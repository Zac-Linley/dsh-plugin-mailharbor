AI proposals for project tasks and on-demand project sessions.

- "AI 提议任务" analyses project notes and open tasks, returns suggestions;
  nothing is created until the user checks items and confirms.
- Project sessions are created only on demand, seeded with the project name,
  recent notes and open tasks (including waiting reasons).
- No automatic session is created when a project is created.
