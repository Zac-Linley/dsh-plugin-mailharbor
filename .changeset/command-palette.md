Project/task command palette in the task panel.

- ⌘K / Ctrl+K opens a searchable palette for projects and tasks.
- Results respect pinned/recent ordering for projects; Enter opens the first hit.
- Quick actions create a task or project from the same palette.
- A search icon in the task header opens the palette for pointer users.
