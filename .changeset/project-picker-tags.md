Searchable project picker, tags and archived handling.

- The task editor replaces the native project select with a searchable picker:
  search name/tags, pinned first, recent order, "无项目" option.
- Projects can be tagged from the detail header; search matches tags.
- The project drawer hides archived projects from 全部; they only appear under
  已归档.
